## 三、阻塞与备选预案

| 风险 | 备选方案 |
|---|---|
| npm 源不可达 | 切换国内镜像（npmmirror）→ pnpm/bun → 离线依赖包；仍不可行则上报用户 |
| 上游内容口径冲突 | 以仓库 commit `02523ae` 文件为唯一基线，页面显著标注基线版本 |
| 演示与真实行为有出入 | 演示区一律标注「交互模拟」，附上游官方文档链接 |
| 浏览器抽查不可用（file:// 不受支持） | 用 `npm run preview` 起本地静态服务后走 http://localhost |
