# Pyknora 知识库问答 · 使用说明

> 零基础友好版：照着做就能演示，不需要懂代码。

---

## 一、这是什么

一个可以直接在浏览器里使用的「知识库问答」界面：

- **对话问答**：像聊天一样提问，回答逐字出现，并标注答案来自哪份文档（可以点开看出处原文）。
- **文档管理**：把 PDF / Word / Markdown / 文本拖进页面，系统自动"读懂"它（解析→分段→建索引），之后就能就这份文档提问。

---

## 二、怎么启动（三选一）

### 方式 A：一键启动（推荐）

双击 pyknora 目录下的 **`启动演示.bat`**。它会：

1. 弹出两个黑色窗口（后端服务和文档处理worker）——**不要关闭它们**；
2. 稍等 6 秒自动打开浏览器界面。

### 方式 B：后端已在运行时，直接打开界面

双击 `front-end page\pyknora-web\dist\index.html` 即可（单文件，无需服务器）。

### 方式 C：开发模式（改代码时用）

```bash
# 窗口 1：后端（在 pyknora 目录）
uv run uvicorn app.main:app --port 8000
# 窗口 2：前端（在 pyknora-web 目录）
npm run dev
# 浏览器打开 http://localhost:5173
```

## 四、界面使用

### 对话问答（默认页）

- 空状态有**示例问题**，点一下即可直接提问；
- 输入框里按 **Enter** 发送，**Shift+Enter** 换行；
- 回答逐字出现，生成中可点「停止」；
- 回答下方有一条**来源占比条**和几个**文件芯片**（如 `doc_ml.txt ×2`）：
  - 占比条越宽 = 这份文档贡献的依据越多；
  - 点文件芯片可展开**原文片段**（第 N 段 · 第 N 版）；
- 每份文档有一个固定颜色，对话里和文档管理页保持一致。

### 文档管理（左侧栏 →「文档管理」）

- **上传**：把文件拖进虚线框，或点虚线框选择文件（可多选）；
  - 支持 PDF / Word(.docx) / Markdown(.md) / 文本(.txt)，单文件最大 20MB；
- **状态**：每行右侧显示状态——
  - 🌘 **处理中**（彩色旋转环）：正在解析建索引，页面会自动刷新，一般几秒到几十秒；
  - 🟢 **就绪**（绿点）：可以就它提问了；
  - 🔴 **处理失败**（红点）：请检查文件内容或格式；
- 上传同名文件会自动**追加新版本**（版本号 +1），问答始终用最新已就绪版本。

### 主题切换（右上角四个圆点）

暖纸（默认）/ 纯白 / 深黑 / 彩虹·晨光，点击即换，选择会被记住。

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 一直显示「登录中」或提示登录超时 | 后端没响应。关闭黑色窗口后重新双击 `启动演示.bat`；仍不行则重启电脑后再试 |
| 侧栏显示「服务未连接」 | 后端没启动。用方式 A 启动 |
| 上传后一直「处理中」 | 文档处理 worker 没运行（`启动演示.bat` 的第二个黑窗口）。重启它 |
| 提示「登录已过期，请重新登录」 | 登录凭证 5 小时有效，过期后重新登录即可，聊天记录在本页内仍保留 |
| 想删除文档 | 网页版暂不支持（后端删除需审批流程，见验收报告"已知边界"） |

---

## 六、演示建议路径（无人讲解也能走通）

1. 打开界面 → 登录（10 秒）；
2. 对话页点示例问题「弹性伸缩是怎么计费的？」→ 看逐字回答；
3. 回答下方点 `doc_cloud.txt` 芯片 → 看原文片段与版本号；
4. 切到右上角第 4 个圆点（彩虹·晨光）→ 展示彩色渐变主题；
5. 左侧栏「文档管理」→ 拖入一份 txt → 看彩色旋转环 → 几秒后变绿点「就绪」；
6. 回对话页就刚上传的文档内容提问 → 回答引用它，颜色与文档列表一致。
