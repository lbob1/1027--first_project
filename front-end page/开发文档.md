# Impeccable 使用指南 — 开发文档

## 一、技术栈与约定

- **Vite 5 + React 18 + TypeScript（strict）+ Tailwind CSS 3**；图标 lucide-react；趋势图为手写 SVG；未引入 UI 大库。
- 视觉方向：暖纸（#faf6ef）+ 墨色（#221f1b）+ 朱红（#b23a24）编辑风，衬线展示字体 + 系统无障碍正文栈——刻意避开检测器点名的默认套路（Inter / 紫蓝渐变 / 卡片套卡片）。
- 产物经 `vite-plugin-singlefile` 内联为单文件 `dist/index.html`（JS/CSS 全部自包含），file:// 双击可直接打开，也可托管；入口配置见 `vite.config.ts`（`base: './'`）。

## 三、三大核心组件状态机

| 组件 | 状态流转 | 要点 |
|---|---|---|
| WorkflowStepper | `openStep ∈ {1,2,3}` | 进入视口自动播放（2.8s/步，reduced-motion 不播放）；节点 2 带「可选」分支；点击展开 做什么/说什么/产出什么 |
| CommandReplay | `idle → typing → sent → report` | 70ms/字回放（reduced 直切）；sent 态双评审并行动画 1.4s；report 含 10 启发式评分表、P0~P3、趋势折线、persona 红旗、推荐命令序列（终章 polish） |
| LiveSimulator | `off → live → selected → generating → variants → accepted` | 徽标样式复刻图三；卡片点选蓝描边；V1/V2/V3 三主轴热切换；`--p-density/--p-color` CSS 变量旋钮零延迟；Accept 绿闪 + 写回提示，Discard/重置还原 |

## 四、交互与无障碍约定

- scrollspy：IntersectionObserver（rootMargin -15%/-60%）→ 侧栏高亮 + `history.replaceState` 同步 hash；
- 搜索：命令 + 章节联合匹配；`/` 聚焦（移动端先开抽屉）、↑↓ 选择、Enter 跳转、Esc 清空；
- 抽屉/移动导航：`role="dialog" aria-modal`，打开聚焦关闭按钮、关闭焦点还原、body 滚动锁；
- 动效只服务状态反馈；`prefers-reduced-motion: reduce` 全局降级（CSS 强制 + JS 直切）；
- 复制按钮：Clipboard API + `execCommand` 回退（file:// 可用），✓ 态 2 秒自动还原。

## 五、常用命令

```bash
npm install        # 安装依赖
npm run dev        # 本地开发
npm test           # vitest 单元测试（13 例）
npm run build      # tsc 类型检查 + 产出 dist/
npm run preview    # 本地预览 dist/（默认 4173 端口）
```
